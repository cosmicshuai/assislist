# Todo System

Personal productivity system: capture tasks from WhatsApp (text/voice), AI
breaks them into context-rich subtasks with urgency and dependencies, managed
in a self-hosted web app with a clean UI and a machine-readable API.

## Status
- SDD Phase 0 complete (constitution + templates + scaffold).
- Vikunja rejected and removed; building from scratch per SDD.

## Stack
Node + Express (ESM) · node:sqlite · drizzle-orm · React + Vite
